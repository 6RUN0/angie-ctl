# История изменений

В этом файле документируются все значимые изменения проекта.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

Англоязычная версия файла — [CHANGELOG.md](CHANGELOG.md).

## [Не выпущено]

### Добавлено

- Команда `status`: выводит `[on ]`/`[off]` для каждого имени и завершается с кодом
  `0` только если включены все запрошенные имена, что позволяет использовать её в
  условиях.
- Команда `prune`: удаляет все осиротевшие включённые симлинки (активные, но без
  источника в каталоге доступных).
- `ls` во втором проходе помечает включённые записи без источника как `[orphan]`.
- Опция `-r`/`--reload`: запускает `ANGIE_RELOAD_CMD` (по умолчанию `$ANGIE_BIN -s
  reload`) после успешного батча.
- Опция `--rollback`: откатывает ровно изменения текущего запуска, если проверка
  конфигурации после батча провалилась (нельзя сочетать с `--no-test`).
- Опции `-n`/`--dry-run` и `-T`/`--no-test`.
- Проверка конфигурации: `$ANGIE_BIN -t` запускается один раз после успешного батча
  `en`/`dis`/`prune` (пропускается при `--dry-run`/`--no-test` или при отсутствии
  бинаря).
- Инструменты проекта: `Makefile`, герметичная сюита `test.sh`, контейнерный
  интеграционный тест `test-container.sh` и CI на GitHub Actions.

### Изменено

- Проверка конфигурации и перезагрузка резолвятся и выполняются с фиксированным
  доверенным `PATH` (`SAFE_PATH`, `/usr/sbin:/usr/bin:/sbin:/bin`), чтобы
  унаследованный/враждебный `PATH` не мог их подменить; абсолютный `ANGIE_BIN`
  обходит lookup.
- Провалившаяся проверка конфигурации теперь по умолчанию оставляет изменения на
  месте с информативным сообщением; `--rollback` включает их откат.
- `do_rollback` читает undo-лог из here-document, а не из пайпа, поэтому выполняется
  в текущем shell, считает неудавшиеся шаги отката и сообщает о неполном откате через
  `finalize_batch`.

### Исправлено

- Устранено противоречие в выводе при ошибке: при `--rollback` запуск больше не
  печатает «changes left in place» прямо перед сообщением об откате.
- Пустой таргет от `readlink` не записывается в undo-лог (с предупреждением) вместо
  записи, которую откат не сможет воссоздать.

### Безопасность

- `is_safe_name` отклоняет пустое, `.`, `..` и любое имя со слэшем, блокируя обход
  пути; теперь также отклоняет таб и перевод строки, чтобы имя не могло испортить
  undo-лог отката.
- `ANGIE_ETC` проверяется при старте: должен быть абсолютным путём без сегментов `..`
  и `//`.
- `do_disable`/`do_prune` удаляют цель только после подтверждения, что это симлинк,
  поэтому реальный конфиг, положенный вручную, никогда не удаляется.

### Документация

- Задокументирована граница доверия `ANGIE_RELOAD_CMD`: значение исполняется как
  командная строка (с разбиением по пробелам) с привилегиями процесса, поэтому
  задавать его должен доверенный оператор, а не пробрасывать менее доверенный
  вызывающий (при обёртке в sudo исключайте через `env_delete`). `SAFE_PATH` защищает
  только резолв первого слова команды.
